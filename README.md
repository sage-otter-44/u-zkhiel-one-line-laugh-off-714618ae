One funny line for the make.fun One-Line Laugh-Off bounty. `main.ts` writes a single joke (1–200 chars) to `/output/entry.txt`, judged pairwise by an AI comedy judge.

Run: `node main.ts` (or `npx tsx main.ts` if a TS runner is needed — the file is plain Node-compatible TypeScript with no type annotations).
